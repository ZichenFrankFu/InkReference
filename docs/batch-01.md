# 第一批：素材库基础与复用验证

## 交付范围

本批建立可运行的 Python/FastAPI 后端、React 前端、SQLite 迁移与 Windows 安装启动脚本；打通作品、人物、桥段 CSV 的导入、管理和导出。

全文清洗、LangGraph 提取、Skill 上传、模型接入、token 计数及 EXE 安装包在后续批次完成。第一批保留复用调查和离线检查依据，不能将规则样本验证描述为真实模型评测。

## 真实 CSV 验收基准

输入来自用户提供的 v8 文件，原件不提交到仓库，也不由测试修改。

| 文件／关系 | 基准数量 |
|---|---:|
| `works_library_v8.csv` | 536 条作品 |
| `character_database_v8.csv` | 1,213 条人物 |
| `cliche_database_v8.csv` | 138 条桥段 |
| 作品与桥段关系 | 1,155 条 |

需保留具体版本、同名作品、原始 ID、中文字段、引号、逗号、多行单元格、未知状态和不同日期精度。不能以“导入没有报错”替代语义往返验证。

## 必须通过的检查

1. 三文件一起预览并提交后，四项统计与基准一致；所有人物关联有效作品，作品与桥段两侧一致。
2. 兼容导出后重新导入空数据库，逐记录、逐字段与原始解析结果比较；关联集合相同。
3. 同一批重复导入并选择跳过时，数据及关联数量不变。更新与报错策略分别验证，不隐式覆盖现有记录。
4. 错误 ID、缺失引用、无效 CSV 和冲突关系阻止写入；整批失败时验证数据库未被部分修改。
5. 创建和修改记录可回读；过期 revision 返回冲突。有关联的删除受到保护，确认级联后按声明处理关系。
6. 搜索、分页、按作品／桥段过滤和关联查看使用真实 API，结果与数据库一致。
7. 单表、兼容和完整导出可下载；CSV 为 UTF-8 BOM，完整模式包含每张业务表和 manifest。
8. 后端测试通过，前端类型检查及生产构建通过；使用合成夹具覆盖数据边界。
9. Windows 实机运行安装脚本、启动 GUI、完成导入和导出；验证中文及空格路径、端口占用信息、可更换端口和停止服务。

Linux 环境可以完成数据和 API 检查以及前端构建。Windows PowerShell 5.1、终端交互和浏览器自动打开需要实机验收，不用 Linux 检查替代。

## 复用验证的解释

复用优先考虑 InkOctoBot 的中文分章、清洗规则和剧情提示词，以及候选项目的长文覆盖、断点处理与证据定位设计。来源提交、具体文件、许可证及适配记录见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

本批离线比较着重检查输入保真、无标题全文覆盖、超长章节尾部及噪声边界；即使这些检查通过，也只能说明规则或固定夹具下的行为。真实本地模型和 API 尚未运行比较，提取质量、token、费用和 Windows 模型兼容性均待后续测量。

接入提取器前，使用同一组中文样本比较人物事实、事件、桥段与原文证据，记录输入覆盖率、证据定位、人工修改量、实际 token 与耗时，再确定默认实现。
